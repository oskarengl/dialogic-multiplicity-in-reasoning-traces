# Working notes

Process records from while the study was running. Not part of the result. Where a note and
the paper disagree, the paper is current.

| File | What it is |
|---|---|
| `STATUS.md` | Running log of decisions and changes, in order |
| `Findings.md` | Early exploratory findings |
| `RECLEAN_RUNBOOK.md` | Procedure followed when the dialogue cells were re-cleaned after the speaker-label leak |
| `RUN_CELL5.md` | Operational notes for generating the DeepSeek-R1 traces |
| `HANDOVER.md`, `HANDOVER_plots.md` | Session handover notes, including the state of the plotting code |
| `FEEDBACK_AND_FORWARD_PLAN.md` | Supervisor feedback and the plan that followed it |
| `research_plan.md` | Original project plan, predating the frozen method specification |
| `classification_methods_sources.md` | Literature survey done while choosing the three methods |
| `add-to-paper-at-some-point.md` | Loose ends |
| `free-models.txt` | Model APIs that were free at the time |
| `drafts/` | Superseded paper versions, `main_v2` through `final_v4`, and the earlier `references.bib` |

`STATUS.md` and `research_plan.md` describe the per-method gates as the live framework, and
`STATUS.md` records Method 3 as excluded on its κ shortfall. The paper applies a single
validity check to all three methods instead; see
[`../preregistration/DEVIATIONS.md`](../preregistration/DEVIATIONS.md).

The frozen specification is at [`../preregistration/methods.md`](../preregistration/methods.md).
