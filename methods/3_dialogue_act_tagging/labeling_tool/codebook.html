Notes specific to this dataset

    One-line decision path

    1. Is it asking for something? → Information-seeking (then: open Yes/No, hunch-check, wh-, or explicit list?)
    2. Is it giving information? → Information-providing (then: solicited → answer, unsolicited → inform, or a yes/no/correction about someone's claim?)
    3. Is it about an action? → who does it: speaker → Commissive, addressee → Directive.
    4. Is it about understanding rather than content? → Feedback.
    5. Is it empty (time-buying, abandoned, ritual)? → Time Mgmt / OCM / Social.
    6. Only if none of the above genuinely fits → none.
